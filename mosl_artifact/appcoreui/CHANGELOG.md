Summary
=======
This library provides a BaseActivity, BaseFragment, 
BaseBottomSheetFragment, BaseDialogFragment classes

It uses Timber for logging.
It depends on androidx annotation, appcompat, recyclerview & material support lib. 
It also depends on rxjava2, kotlin, dagger..
It also defines appcore and navigator packages from MofslArtifacts
